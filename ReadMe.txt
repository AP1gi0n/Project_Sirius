Full Description:

	Project Sirius is an affordable, low power, custom stream deck powered by an ESP32-S3-WROOM and a 4.0 inch 320x480 resolution capacitive touch screen, with bridging hardware and host systems via a 
custom-built C++ communication software. Features a PCB utilizing the ESP32-S3-WROOM with an onboard PCB antenna for wireless Bluetooth capabilities alongside a modern USB Type-C port paired with a TPD4E02B04DQ
AR array for circuit protection. Incorporates a W25Q32JVSSIQ flash memory chip to handle high-speed data transfer and smooth asset management. 
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Current Status:
	
	Project Sirius is currently in early development. Planned features include dual Bluetooth and USB connection options, a seamless UI design for the touch screen, a 3D-printed desk mount at an 45 degree 
angle for optimal viewing, and pre-built modules allowing users to easily control programs like Spotify and Elgato WaveLink directly from the device.

NOTE!: As of current development, only the schematic file for Project Sirius is being worked on.
